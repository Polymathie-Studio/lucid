What this proves, and what it does not

    
One JSON node carries all of it: SKOS relations for the ontology, an ordered lucid:depth list that is a separate axis from those relations, a lucid:source pointer, and an optional lucid:visual as a declarative Vega-Lite-shaped spec whose data is a named, deferred source. The dataset toggle swaps the instance data the host injects while the node itself does not change, which is the type versus instance boundary holding in practice. Where a claim carries its own qualifications, what it rests on and what would break it, those sit as ordinary content in the depth tiers, in both directions, not as a rung the standard weighs.

    
One honest limit. The chart here is drawn by a small inline interpreter of the spec so the page stays self-contained with no dependency; in production the same spec is handed to the real Vega-Lite runtime, so this is one model over two renderers, not one engine.
